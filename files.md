# Project Files Information

This document provides a complete overview of the files and directories present in the `STUDENT FEEDBACK MANAGEMENT SYSTEM_27_09_2026` project directory.

## Core Application Files

* **`app.py`**
  * **Size:** ~5.5 KB
  * **Description:** The main entry point for the Streamlit application. It contains the user interface definitions (5 pages) including Submit Feedback, View Feedback Records, Rating Summary, Course-wise Summary, and Database Info.
  * **Key Components:** Uses `streamlit` for UI and imports `database.py` for all DB operations.

* **`database.py`**
  * **Size:** ~4.8 KB
  * **Description:** The data-access layer. It handles all interactions with the SQLite database to keep the Streamlit app lightweight.
  * **Key Components:** Database initialization (`init_db`), table creation, inserting feedback, querying averages, and retrieving data for the summaries.

* **`seed_data.py`**
  * **Size:** ~1 KB
  * **Description:** An optional utility script to populate the database with sample feedback records (10 sample records). Useful for populating initial data to test the UI.

* **`feedback.db`**
  * **Size:** 12 KB
  * **Description:** The local SQLite database file generated by `database.py`. It contains the `feedback` table which stores all the submitted data.

## Configuration & Scripts

* **`requirements.txt`**
  * **Size:** 40 Bytes
  * **Description:** Contains the Python dependencies required to run the project (`streamlit>=1.40`, `pandas>=2.0`, `pytest>=8.0`).

* **`run_app.bat`**
  * **Size:** 181 Bytes
  * **Description:** A Windows batch script for a one-click setup and execution of the app. It creates the virtual environment, installs requirements, and runs `app.py`.

* **`.gitignore`**
  * **Size:** 134 Bytes
  * **Description:** Specifies intentionally untracked files that Git should ignore (like `venv`, `__pycache__`, etc.).

## Directories

* **`.streamlit/`**
  * **Description:** Configuration directory for Streamlit. Contains `config.toml` for setting UI theme (e.g., Light theme).

* **`tests/`**
  * **Description:** Contains test scripts for the application. Specifically unit tests for the database operations (`test_database.py`) and headless Streamlit UI tests (`test_app.py`).

* **`screenshots/`**
  * **Description:** Contains evidence screenshots demonstrating the working features of the app.

* **`venv/`**
  * **Description:** The Python virtual environment directory containing local package installations and python executables.

* **`__pycache__/`**
  * **Description:** Automatically generated Python bytecode cache folder to speed up execution.

* **`.git/`**
  * **Description:** The hidden directory containing the local Git repository data, tracking version history.
